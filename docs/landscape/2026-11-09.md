## Worth stealing

- **Steer a message into the running turn at its next tool call.** claudecodeui
  1.37.8 adds it for Claude sessions
  ([#1760](https://github.com/siteboon/claudecodeui/pull/1760)): a message sent
  mid-turn lands between tool calls instead of waiting for the turn to end or
  interrupting it. Touches: the Send now work (roadmap plan item 4), which today
  interrupts the turn; a third choice, "add to this turn", may suit short
  corrections better than a stop.
- **Side questions answered by a separate session.** claudecodeui 1.37.8 answers
  a side question with each provider's own session
  ([#1673](https://github.com/siteboon/claudecodeui/pull/1673)), so asking "what
  is that?" does not disturb the working turn. Touches: our patterns/explain
  and the fast-model chain; compare asking a question about a reply without
  adding to the main thread.
- **Voice call hygiene: silence clock and call item.** happy's iOS app now has a
  voice call that restarts its silence clock on the person's voice, warns at
  180 s and ends at 290 s, and its dictation picks between two languages at each
  pause (commits on slopus/happy, 11-02 to 11-08). Touches: hands-free mode's
  idle timeout and spoken warning; bilingual dictation if David wants it.
- **Webhook channel for run lifecycle events.** claudecodeui adds an opt-in
  webhook for run lifecycle events
  ([#1714](https://github.com/siteboon/claudecodeui/pull/1714)); omnara shows
  agent status as GitHub checks on pull requests
  ([#730](https://github.com/omnara-ai/omnara/pull/730)). Touches: alerts and
  notifications; a generic webhook out of sessiond would feed ntfy-style
  receivers without app work.
- **Show MCP elicitation requests instead of declining them.** claudecodeui
  now surfaces MCP elicitation
  ([#1725](https://github.com/siteboon/claudecodeui/pull/1725)) where it used to
  decline unseen. Touches: question cards; check that an MCP elicitation inside a
  headless session reaches the app as a card and is not silently refused.

`browser_upload_file` tool, a binary viewer with download, and opencode history
read one page at a time.

**anomalyco/opencode** — v2.2.6 (11-06) and process-daemon v0.5.0. A touch dock
for composer actions above the keyboard on phones and tablets

starts a session in a new worktree; `--archived` keeps scripted sessions out of
lists; `opencode run` now waits for background jobs it started and exits 143 on
SIGTERM; opt-in MCP connection pooling. Nothing on voice.

**omnara-ai/omnara** — omnarad/cluster v0.2.16 and v0.2.17 (to 11-04). Agent
status as GitHub checks (above) and small fixes, among them an Enter that

**amantus-ai/vibetunnel** — Nothing notable; dormant.

**getpaseo/paseo** — v0.15.0 (11-03) to v0.15.3 (11-06). Release notes repeat
last week's beta items (terminals survive restarts, opt-in agent recovery),
plus: large daemon responses split across relay frames instead of disconnecting
([#8302](https://github.com/getpaseo/paseo/pull/8302)); oversized chat entries

([#8274](https://github.com/getpaseo/paseo/pull/8274)); subagent activity in its

**mbailey/voicemode** — No release since v9.0.2; recent commits announce a

**Claude Code (official)** — v2.1.317 to v2.1.319 (11-03 to 11-06), from the
release notes. Relevant: `permissions.denyInsteadOfPrompting` (2.1.319), which
denies a call that would wait on a prompt and continues the turn, a possible
setting for unattended sessions; MCP tasks moved to the background with the
result reported on finish (2.1.319); an "Earlier in this session" row in
`/tasks` to reopen finished subagents (2.1.319); a message sent after a model
change no longer running after Stop in headless sessions, and a restarted
session no longer re-sending a failed message ahead of newer ones (2.1.318);
`/remote-control` no longer showing a session available after a failed
connection (2.1.318); the iPhone app no longer showing a cloud turn as finished
while it runs (2.1.318); `claude -p` now exits 1 when a full disk loses the
transcript (2.1.317); the second of two simultaneous permission prompts now
shows its command on mobile (2.1.317); a warning before a web or shell tool call
sends the account email to the network (2.1.317). The `CLAUDE_CODE_RESUME_INTERRUPTED_TURN`
fix touches plan mode. No voice items; `/voice` is still input only. Reminder:
Opus 4.8 fast mode is removed 2026-11-30 (checked last week, no pins).
