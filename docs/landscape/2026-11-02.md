## Worth stealing

- **Resume interrupted agents after a host restart.** paseo 0.15.0-beta.1
  keeps terminal programs running across daemon restarts and crashes, and
  automatically resumes interrupted agents in their existing conversations
  ([release](https://github.com/getpaseo/paseo/releases/tag/v0.15.0-beta.1),
  [#8127](https://github.com/getpaseo/paseo/pull/8127)). Touches: the
  sessiond drain-and-resume path in `media restart-services`; compare what we
  resume after a crash (not only a planned restart) and whether the user is told.
- **Long-press Send to queue or send now.** paseo 0.14.0 adds long-press on
  Send to choose between queueing a message and sending it immediately
  ([#7897](https://github.com/getpaseo/paseo/pull/7897)); Claude Code 2.1.312
  adds click-to-send on the "to send now" hint under a queued message. Touches:
  the Sasonica composer's queued-send: one gesture to promote a queued message.
- **Pending questions survive other messages.** paseo keeps pending questions
  and approvals after peer messages arrive
  ([#8453](https://github.com/getpaseo/paseo/pull/8453)), and question cards
  gained clickable links and selectable descriptions
  ([#7419](https://github.com/getpaseo/paseo/pull/7419)). Touches: our
  question cards and the rule that a headless `media session send` is queued
  behind a card: add a test that a card stays up through any inbound message.
- **Collapse finished turns into summaries.** paseo 0.14.0 can fold completed
  conversation turns into a summary and expand them ([#7785](https://github.com/getpaseo/paseo/pull/7785),
  [#8109](https://github.com/getpaseo/paseo/pull/8109)); phones open a
  subagent in place of the list with Back returning to it
  ([#8093](https://github.com/getpaseo/paseo/pull/8093)). Touches: long threads
  in the app and the subagent view.
- **Voice mode opt-in, with one-tap local model download.** paseo 0.14.0 makes
  voice mode opt-in and adds downloadable local speech models in Voice
  settings. Touches: Settings voice section (an off-by-default voice plus a
  visible "get this model" step instead of a config edit).

## Plan

Added the same day, after checking each item against the code. In order, smallest first.

1. **A question card outlasts inbound mail** (agent-media, test only). The
   rule that `media session send` queues behind a card has no test that the
   card is still up, and still answerable, after a peer message arrives.
   Add one to `packages/server/tests/test_headless.py` beside
   `test_a_message_typed_over_a_question_answers_it`: a signed peer message
   must queue, not answer the card. Fix sessiond only if it fails.
   *Done 2026-11-02:* the direct case was already tested; the missing one
   (mail held for a restart, a card up by the time it is due) is now in
   `test_sessiond_restart.py`, and sessiond passed it unchanged.
2. **Opus 4.8 fast mode retires 2026-11-30** (host check, no code). No pin
   found in agent-media or the app; check `~/.claude/settings.json` and
   each host's sessiond env for `--model` or fast-mode pins before the date.
   *Done 2026-11-02:* none. Claude Code's setting is the `opus` alias with
   no fast-mode key, sessiond and the app name no model, and the two
   `claude-opus-4-8-liberated` visual models in red5's env go through the
   gateway's API, which the fast-mode retirement does not touch.
3. **Say when a session was resumed** (agent-media, then the app). sessiond
   already resumes cut-off sessions after a planned restart and after a
   crash (`cut_off`, `resume_note`), which is what paseo just shipped. The
   gap is the user's side: the model is told, the thread is not. Add a
   thread-log event when `resume_note` is sent ("resumed after a restart",
   with what it was doing), and have the app show it as a muted line.
4. **Send now on a queued message** (app, using sessiond's `interrupt`). A
   message sent mid-turn waits behind the turn. Give its bubble a "send
   now" tap (and long-press on Send for the same choice): interrupt the
   turn, then deliver it. Background agents are spared by
   `perTaskStopAffordance`. Needs a contract note in docs/server-contract.md.
5. **Enter on an on-screen keyboard** (app, check). `GrowingLine` sends on
   Enter and folds newlines by design; confirm the main composer keeps
   Enter as a newline on a touch keyboard, as claudecodeui just fixed.

Not taking up: folding finished turns (threads are read aloud and kept
short; revisit if long threads become a complaint) and opt-in voice (the
voice is the product, not an add-on). The suggested repos are for the
watchlist, which this plan leaves unchanged.
