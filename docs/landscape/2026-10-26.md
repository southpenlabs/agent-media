(window: since 2026-10-19; merged PRs and release notes read), WebSearch for
Claude Code, the non-GitHub items and discovery. All repos still exist at the

new in the last month.

## Worth stealing

- **Keep every follow-up queued while a turn runs.** claudecodeui fixed
  follow-ups being lost or fired early while a turn was running
  ([PR #1634](https://github.com/siteboon/claudecodeui/pull/1634)), and names the
  permission mode in the composer
  ([#1631](https://github.com/siteboon/claudecodeui/pull/1631)). Continues the
  queue thread from the last two digests. Touches: the Sasonica composer's
  queued-send (a queue must hold several, in order) and showing the current
  permission mode on the phone, next to the send button.
- **Prefetched voice replies must keep every sentence.** paseo fixed a bug where
  prefetched speech dropped sentences
  ([PR #7756](https://github.com/getpaseo/paseo/pull/7756)). Touches: our
  read-ahead and clip cache for speech (and the new music-bed/Read it
  readings): add a test that the spoken sentences equal the text's sentences
  when chunks are fetched early or out of order.
- **Skip a bad line, keep the rest of the transcript.** claudecodeui now skips
  malformed JSONL lines instead of dropping the remainder of the file
  ([#1643](https://github.com/siteboon/claudecodeui/pull/1643)); a session
  watcher's ignore list also silently stopped working
  ([#1638](https://github.com/siteboon/claudecodeui/pull/1638)). Touches: the
  thread stream and history reader for Claude transcripts, which we read while
  the agent is still writing (a half-written last line is the usual cause).
- **Relay connections must require the daemon password; say "Host not found".**
  paseo 0.13.0 makes relay connections require the daemon's password when it
  has one ([#7668](https://github.com/getpaseo/paseo/pull/7668)) and shows
  "Host not found" for Android DNS failures instead of a generic error
  ([#7701](https://github.com/getpaseo/paseo/pull/7701)). Touches: the
  off-the-tailnet relay (a relay path must be no weaker than the direct one;
  worth re-checking our scoped credential is required on every route) and the
  app's unreachable-host message, which should name the cause.
- **Voice names resolve completely or fail.** voicemode 9.0.0 turns a voice it
  cannot place into an error naming the cause, not a silent fallback to the
  default, and cuts its tool description from ~2,400 to ~190 tokens
  ([release notes](https://github.com/mbailey/voicemode/releases/tag/v9.0.0)).
  Touches: voice selection in Settings and `MEDIA_*` voice variables (a
  misspelt voice should say so, not change the speaker), and the size of the
  MCP tool descriptions our servers expose.

**Claude Code (official)** — v2.1.303 to v2.1.310 (10-17 to 10-23), from the

and long foreground sleeps blocked there (2.1.310); a question's auto-continue
timeout no longer firing as an external editor closes (2.1.310); many sandbox

## Suggested additions

- [Forge Remote](https://apps.apple.com/dk/app/forge-remote/id6760141378) —
  closed-source iPhone app for Claude Code, Aider and Codex CLI sessions on a
  desktop; worth a look only for its phone UX.
- [Claude Remote Hub](https://zilliz.com/blog/3-easiest-ways-to-use-claude-code-on-your-mobile-phone)
  — a ~1,000-line stdlib-Python session server reached over Tailscale; a small
  contrast with our server, and another tailnet-only design.
- [noisy-coding](https://hub.docker.com/r/noisy/noisy-coding) — always-on
  listener whose speech reaches Claude mid-task (Grok STT/TTS); last updated
  09-02. A reference for mid-turn voice messages, like our barge-in.
- [cc-hooks (husniadil)](https://skillselion.com/plugin/husniadil/cc-hooks) —
  plugin of hook-driven TTS and sound cues with several providers; compare
  with our `[[sound: ...]]` markers.
- Earlier suggestions (cicero, Heard, agent-code-tts, CC Pocket, 247-claude-code-remote,
  claude-code-voice-hook, Rhyme, AgentsRoom) still stand; none re-checked.
