# Landscape watch — 2026-11-16

Scope: `gh` (releases, release notes, recent commits since 2026-11-09) for the
seven GitHub entries, voicemode, anthropics/claude-code, hapi and happier;
WebSearch for Claude Code, the non-GitHub items and discovery. All repos still
exist at the watchlist names; none moved or archived. vibetunnel is still
dormant (last push 08-05). Searches returned mostly older roundups and no clear
new project from the last month. Claude Code section is from GitHub release
notes (v2.1.320 and v2.1.324 have no release entry).

## Worth stealing

- **Background tasks shown above the composer, each with a Stop button.** paseo
  0.16.0-beta ([#6220](https://github.com/getpaseo/paseo/pull/6220),
  [#9162](https://github.com/getpaseo/paseo/pull/9162)) lists the shells and
  monitors an agent is running, across Claude Code, Codex and OpenCode. claudecodeui
  also now reports a background-task stop that does not take
  ([#1762](https://github.com/siteboon/claudecodeui/pull/1762)). Touches: the
  thread view and Send now; a visible "still running" strip tells David why a
  reply has not come.
- **Subagents return at once and report back when idle.** opencode v2.3.0 makes
  every subagent a background one
  ([#63382](https://github.com/anomalyco/opencode/pull/63382)) and its TUI folds
  each run of tool calls and thoughts into one collapsible row
  ([#63207](https://github.com/anomalyco/opencode/pull/63207)). Touches: opencode
  is now our default agent, so its sessions will show late subagent reports after
  a turn "ends"; check that the app and the spoken-reply hook treat that as a new
  turn, and that a folded activity row is what a phone shows by default.
- **Heartbeat while hooks run long.** Claude Code 2.1.323 sends a progress
  heartbeat every 30 s in `claude -p` and SDK sessions so a host will not end the
  turn as hung. Touches: sessiond's idle/hung detection for headless chats;
  consider counting that heartbeat as liveness.
- **Forked sessions as a tree; load older chats on scroll.** claudecodeui shows
  forked sessions nested under their parent
  ([#1621](https://github.com/siteboon/claudecodeui/pull/1621)) and pages older
  conversations in on scroll
  ([#1784](https://github.com/siteboon/claudecodeui/pull/1784)); hapi adds
  fork/rewind for opencode v2 chats
  ([#2424](https://github.com/tiann/hapi/pull/2424)). Touches: Branch and the
  thread list, plus the proposal to carry a chat to another agent.
- **Question cards that say they are waiting, with the wait counted.** hapi makes
  pending questions read as waiting for a reply, counts wait time on cards made
  before the transcript arrives, and shows cancellation of a dismissed async
  question ([#2390](https://github.com/tiann/hapi/pull/2390),
  [#2397](https://github.com/tiann/hapi/pull/2397),
  [#2341](https://github.com/tiann/hapi/pull/2341)); it also fixes a stale
  "permission required" after the request went inactive
  ([#2415](https://github.com/tiann/hapi/pull/2415)). Touches: question cards;
  test a card whose turn was cut off by a restart.

## Per project

**slopus/happy** — Still no release past CLI 1.2.6-beta.1 (10-09). Commits are
all app work: share links (`link.happy.page`) that open the app as universal /
App Links, links that show a thing's current name, attachments as cards in a
sent message, a "Compute" settings area (shared vs private computers with a
concurrency limit), sidebar titles that fade instead of "…". It also removed its
automatic CI workflows to cut billing. Nothing on voice this week.

**siteboon/claudecodeui** — v1.37.8 is still newest (11-07); commits since:
clear session context (#1787), token usage kept visible while the agent asks a
question (#1785), a queued message sent as soon as the run it waited on settles
(#1697), one held-open scheduled turn no longer blocks every queued message
(#1763), reasoning kept out of side-question answers (#1767), a Linux .deb,
opencode v2 `providers` config read (#1783).

**anomalyco/opencode** — v2.2.7 (11-10) and v2.3.0 (11-13), process-daemon
v0.5.2. Beyond the above: "Jump to message" search across a session's prompts in
desktop; mark sessions read or unread; Copilot Auto model; MCP logins stay
signed in; shell commands survive server handoffs and keep output when
interrupted; experimental MCP events and moving a timed-out shell command to the
background. SDK: `voice.*` endpoints exist and still wait for plugins; worth a
look at what they are, since they are the first voice surface seen in opencode.

**omnara-ai/omnara** — omnarad/cluster v0.2.22 and v0.2.23 (11-13): opt-in
private-network egress allowlists, GitHub commit events steered into running
agents (#810), agent examples. Nothing for the phone UI.

**amantus-ai/vibetunnel** — Nothing notable; dormant.

**getpaseo/paseo** — v0.15.4 (11-10: Claude Fable 5.2 and Mythos 5.2, need Claude
Code 2.1.321+) and v0.16.0-beta.1/.2 (11-10, 11-11). Besides background tasks:
plugins can replace the sidebar with their own layout across hosts and add
composer controls (read/set prompt, attachments, model, mode); diffs open with
the file tree first and load large ones in batches; the chat stays still when a
turn ends and a chat unchanged since last visit shows with no refresh.

**mbailey/voicemode** — No release since v9.0.2 (10-29); no commits since 11-09.
Nothing notable.

**tiann/hapi** (not yet on the list) — v0.34.5 to v0.35.1 (11-10 to 11-14), very
active. Presence badge for every session state, progress bar for hours-long jobs,
tok/s for Claude and Codex rounds, CLI account quotas and rate limits in
Settings → Usage, right-click / long-press menu on project groups, a Cloudflare
Tunnel fix so JSON error bodies survive 502/504, voice backend kept aligned with
its Settings preview, "peer" tools so agents can spawn and ping each other.

**happier-dev/happier** (not yet on the list) — Daily dev builds. Work is
performance and Windows: updates applied once per frame, only the presented
history entry mounted on web, RPC reply ceiling sized to the relay heartbeat,
snapshots bounded at the daemon (large payloads again), subagent lifecycle
preserved, Windows notification click opens the session.

**Claude Code (official)** — v2.1.321 to v2.1.325 (11-09 to 11-13). Relevant:
Claude Fable 5.2 default (2.1.321); `claude remote-control --settings <file>`
applies a settings file to every session it starts (2.1.321); `/compact` showing
twice in Remote Control on web and mobile fixed (2.1.321); `/compact` no longer
summarizes away an unanswered message, and a resumed session no longer joins your
next message to an old interrupted one (2.1.323); 30 s hook heartbeat (above);
Code Mode, an experimental opt-in where Claude writes JavaScript to call tools
(2.1.323); plugin `engines["claude-code"]` range and mod `engine.create` /
`isPromptCovered` support (2.1.323); recent turns missing from a resumed session
after an unclean exit fixed (2.1.325); `/voice` now says what holds the setting
when managed or project settings pin it (2.1.325). `/voice` is still input only,
no native spoken output. Reminder: Opus 4.8 fast mode is removed 2026-11-30.
