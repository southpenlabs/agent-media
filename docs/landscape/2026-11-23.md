GitHub entries plus hapi, happier and anthropics/claude-code; WebSearch for

## Worth stealing

- **Messages from other agents wait for the turn to end.** paseo 0.17.1 makes
  reports from other agents arrive after the current turn instead of
  interrupting it ([#9757](https://github.com/getpaseo/paseo/pull/9757),
  [#10404](https://github.com/getpaseo/paseo/pull/10404)), and lets an agent
  steer or interrupt another's turn and learn how its message was delivered
  ([#10483](https://github.com/getpaseo/paseo/pull/10483)). Touches: `media
  session send` and agent-mail into headless chats, which already queue behind
  a running turn; report the delivery mode back to the sender.
- **Watch a PR and wake the agent on checks, reviews or comments.** paseo 0.17
  ([#10148](https://github.com/getpaseo/paseo/pull/10148)); opencode has the
  matching "tell the agent when watch updates stop waking it"
  ([#65562](https://github.com/anomalyco/opencode/pull/65562)) and MCP Events
  push delivery ([#65271](https://github.com/anomalyco/opencode/pull/65271)).
  Touches: our watcher-outside-sessiond pattern; a first-class "watch" the
  phone can list and cancel beside background tasks.
- **Heartbeats listed and stoppable next to background work.** paseo
  ([#10097](https://github.com/getpaseo/paseo/pull/10097)) extends last week's
  background-task strip to scheduled wakeups; Claude Code 2.1.329 adds the
  session's scheduled tasks, `/loop` wakeups, goal and forks to `/tasks` with
  stop. Touches: the "still running" strip in the thread view.
- **Quota forecast: "your pace uses this up before reset".** paseo
  ([#10289](https://github.com/getpaseo/paseo/pull/10289)) plus provider
  spending and OpenRouter credits in Usage; hapi has account quotas in Settings;
  happier retries usage-limit recovery on a spread schedule
  ([#964](https://github.com/happier-dev/happier/pull/964)). Touches: quota
  alerts and the fast-mode removal on 2026-11-30.
- **A cut-off turn never loses or merges a message.** Claude Code 2.1.327 fixes
  headless sessions losing stored messages when a message is re-sent with the
  same UUID after a kill, and 2.1.330 fixes resume failing on a bad last
  timestamp; hapi keeps Claude alive across compact and clear
  ([#2551](https://github.com/tiann/hapi/pull/2551)). Touches: sessiond drain
  and resume after `restart-services`; test replay with a duplicate UUID.

## Per project

**slopus/happy** — Still no release past CLI 1.2.6-beta.1 (10-09). Commits: model
speed picker (Regular, Fast, Ultrafast) in the composer on both platforms,
Fable 5.2 offered only to CLI 1.2.7-beta.0+, Gemini 4 models in `happy agy`, and
crash reports that carry a no-PII signature. Voice: iOS deleted the relay voice
so the direct call is the only voice; the call's system prompt was rewritten
(shorter, replies "Sent.", verbatim sends, a `skip_turn` tool), other chats' news
is silent context, and the preview gets ten hours of monthly voice.

**siteboon/claudecodeui** — v1.37.9 (11-16). Auth hardening: constant-time key
compare (#1804) and bodies parsed only after authentication (#1805). Also Codex
CLI update from Settings (#1802), refused attachments named instead of dropped
(#1801), Escape in a rename no longer aborts the running turn (#1791), pinned
Claude model versions (#1790).

**anomalyco/opencode** — v2.3.1, v2.3.2 (11-18), v1.19.6, process-daemon v0.6.0.
A timed-out shell command moves to the background instead of dying; compaction
summary written in the background (`compaction.background`); CLAUDE.md read again
when no AGENTS.md; GPT 6.2 prompt-caching fix; plugin updates from Settings;
"Add comment" on selected diff code. Heavy Rust TUI (`cli-rs`) refactor under way.
No voice news.

**omnara-ai/omnara** — omnarad/cluster v0.2.25 to v0.2.27 (11-18 to 11-20):
audio attachments for audio-capable models, Docker machine pool, scheduled agent
inputs with tools, MCP server card. Nothing for the phone UI.

**amantus-ai/vibetunnel** — Nothing notable; dormant.

**getpaseo/paseo** — v0.16.1, 0.16.2, 0.17.0-beta.1, 0.17.1 to 0.17.3
(11-17 to 11-22). Beyond the above: start a workspace in an existing worktree or
from a PR; update provider CLIs from the app; Antigravity provider with
approvals; Rewind in Command Center; background refresh of provider catalogues;

**mbailey/voicemode** — v9.1.0 (11-22), first release since 10-29. Notable:
failing over from Kokoro to OpenAI no longer silently swaps the voice
(`af_sky` to `nova`, a billed call) and the real error shows; configurable STT
timeout; `conch status` names each session; Cartesia moved off sonic-2 before its
sunset; macOS playback-race fixes in the "mouth" (drain judged on progress).

**tiann/hapi** — v0.36.0 to v0.36.5 (11-16 to 11-18), plus commits. Import local
sessions from Pi, OpenCode, Codex and Claude through one registry (#2435);
Active and Working filter lenses and combined filters in the session list;
read state persisted over HTTP; fork and rewind a Claude conversation at a
message (#2417); background-only work shown as a static blue dot; lots of CLI
memory and idle-polling cuts.

**happier-dev/happier** — Mobile and desktop v0.2.22 (11-17). Actionable Android
pushes, one plain setting for sends while the agent works, usage rings kept
before takeover of a direct session, session runner retired on Stop and hangup,
replay seeds exclude rolled-back turns, opencode V2 tool calls published.

**Claude Code (official)** — v2.1.326 to v2.1.330 (11-16 to 11-20). Relevant:
`/status` lists broken files, ignored settings and overriding variables (2.1.327);
`CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME` stops `-p --resume` running a
hook-deferred tool call (2.1.328); `mcp_tool` hooks accept `"onFailure": "block"`
(2.1.328); `claude mcp add-json <name> -` reads JSON from stdin (2.1.327);
Remote Control worktree mode no longer deletes a running session's ignored files
(2.1.327); Code Mode allowed with agent teams and with OTel; background sessions
stop before any request if they lose the shell's LLM gateway (2.1.326);
`/export` asks before overwriting; "easel" built-in chart mod (2.1.330); freeze
after compacting a long chat fixed (2.1.330). `/voice` is still input only.
Reminder: Opus 4.8 fast mode is removed 2026-11-30.
